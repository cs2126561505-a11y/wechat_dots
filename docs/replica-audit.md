## 账号目录与进程内存是两个边界

源码以每个账号目录下的 `db_storage` 组织数据库。不同目录可以帮助限制文件选择，但同一 Windows 用户运行的程序仍可能访问多个目录。上游默认按最近修改时间选账号，密钥加载会合并多个位置的缓存；失败后还会尝试其他账号并自动切换。直接调用默认构造函数不符合本项目的显式测试账号绑定要求。[构造与账号选择](https://github.com/fanyuantaier/wechatauto-replica/blob/62503d76a0db069171cb4e42e87090ad285db489/wechatauto/db.py#L499) · [缓存与回退](https://github.com/fanyuantaier/wechatauto-replica/blob/62503d76a0db069171cb4e42e87090ad285db489/wechatauto/db.py#L667)

`_extract_keys_pid` 通过只读权限打开微信进程，用 `ReadProcessMemory` 读取内存，再用指定数据库第一页的 HMAC 验证候选密钥。问题在于 `_find_bytes` 会遍历可读内存区域：HMAC 约束验证结果，不会把前面的内存读取限制为某个微信账号。如果主账号的数据曾处于同一进程，当前审查无法证明扫描不会触及它。这里只确认代码的访问范围，没有证据证明本机已发生串读。[密钥提取](https://github.com/fanyuantaier/wechatauto-replica/blob/62503d76a0db069171cb4e42e87090ad285db489/wechatauto/db.py#L1087) · [内存区域扫描](https://github.com/fanyuantaier/wechatauto-replica/blob/62503d76a0db069171cb4e42e87090ad285db489/wechatauto/db.py#L1176)

因此，虚拟 Python 环境、指定账号目录、关闭自动回退都不能代替主账号隔离。源码也不能证明这种第三方访问是否被平台检测，或量化账号处罚概率；数据访问隔离和平台账号风险须分别判断，不作零风险承诺。

## 2026-10-18：辅助功能开关的单次实测

固定上游实现默认最多轮试四个候选地址，模块身份未使用文件哈希，未落实模块大小范围检查；任何非 1 的原始字节都可能被改写。失败恢复未核对返回值和回读，成功后保留修改。因此本项目没有直接调用原函数。

专用来宾实际加载的 `Weixin.dll` 版本为 `4.1.15.13`，腾讯签名有效，SHA-256 为 `10f8e995453e2da46d4f2b5080cd6da1f13cc5147746adc119ceae38cb039de5`。固定候选 RVA `0x0B135C38` 位于可写、非执行的 `.data` 节及同一模块的已提交映像页；文件内一处比较指令引用该地址。先前只读检查取得原值 0。这些检查约束目标范围，单独不能证明该字节的语义。

所有者随后明确批准一次受控实验。独立脚本只在该测试进程把此字节改为 1，执行有限时长的界面只读检查，再恢复 0 并回读；未更改页面保护、注入代码、轮试其他地址、输入正文或发送消息。控件数量从 7 增至 55，恢复后重新检查又为 7；本轮证据表明接口访问依赖该运行时状态。原遍历深度限制使完整输入框与发送控件尚未取得，后续操作仍待授权和验证。

恢复字节只确认这一地址的原值已恢复，不能证明辅助功能对象等全部客户端副作用均被撤销，也不能撤销可能的服务端记录。测试账号的异常或平台校验风险尚无可靠概率资料。当前一次实验授权已使用，候选完整准入保持未通过。

## 原型的边界

受限加载器核对 `db.py` 的 SHA-256，并执行同一份已验证字节：`1b8958a0e9a3f8d6c2f8fe89acd72c14bb542c3c16635c31b52e05c0f19b247b`。源码获取工具只下载固定文件，不执行安装脚本。

拟议只读流程显式绑定账号目录与进程创建时间，限定客户端版本，按精确群名查找唯一真实群 ID，并以分片的当前最大消息编号建立起点。后续只保留带本次随机测试标记的新文本观察；公开输出不包含正文、真实账号或群 ID。游标与去重记录在同一事务中提交，身份不明、同名群冲突、进程重启或分片变化时停止。

本轮已取得唯一群身份、真实 @ 正向元数据、自身消息及重复读取证据。缺少 @ 字段的语义、数据库一致性的长期表现和断线恢复仍待验证。读取原型的证据不能证明发送通道可用。

`.runtime` 是私密运行目录，并排除在 Git 之外。本轮专用来宾读取已在其中生成整个选定数据库的明文副本；查询限制在目标群和测试时间窗口，不能据此声称解密范围仅包含目标群。应用不主动持久化密钥也不等于保证内存材料不会进入系统换页或故障转储。缓存和原始证据仅保留在来宾私密目录。

## 进入下一阶段需要的证据

专用环境只登录测试账号，不复制主账号数据库、密钥缓存或宿主用户目录。虚拟机需核对共享磁盘、文件夹、剪贴板、拖放和同步软件的实际设置；备用机需确认不留主账号数据。隔离应由实际配置和访问权限证明，不能仅依据“这是虚拟机”或账号目录数量。

完成环境审查后，再通过一个可审阅的代码变更加入环境、进程和账号绑定检查，决定是否解除读取门禁。真实 @ 对照、稳定群身份或发送结果确认无法成立时，保持候选未通过，继续评估其他通道。具体操作见[探针说明](probe-guide.md)。
