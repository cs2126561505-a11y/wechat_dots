自动安装文件已生成并检查，移除了 Windows 11 的 CPU、内存、TPM、Secure Boot 和存储检查绕过项。首次登录后的自动登录凭据清理已准备，实际结果待系统安装完成后核对。凭据、自动安装资料和完整诊断日志仅保存在本地受限目录。

从基线 `5487ebce162dd19d7706a33b9d4a61f11536ac3f` 增加 `wechat_probe`、固定源码获取脚本与独立探针依赖。正式配置、事件 Schema、工具契约和原有 17 项测试保持原样。候选固定为 `wechatauto-replica 1.2.6.1` / `62503d76a0db069171cb4e42e87090ad285db489`，路径结论见[源码审查](replica-audit.md)。

Python 3.12 环境下执行 `python -m unittest discover -s tests -v`，34 项测试通过。新增的 17 项检查覆盖精确唯一群身份、平台源字段与正文伪造的区分、未知元数据、合成标记过滤、成员标识、脱敏记录、跨分片去重、事务与重启、源码篡改、异常脱敏，以及隔离门禁先于任何实时入口生效。SQLite 测试完全使用合成数据。
