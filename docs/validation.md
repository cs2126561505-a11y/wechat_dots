## 2026-10-17：首轮群读取完成，完整通道准入仍待验证

2026-10-17，所有者在专用来宾登录测试账号并配合发送对照消息。已绑定唯一的目标群真实 ID、账号身份和当前微信进程。普通文本、真实 @、手打假 @、自身消息共四个样本在测试启动后的窗口内取得；所有者改用便于手机输入的短文本，样本依据操作说明、发送顺序与发送者身份对应，未把正文标签当作平台触发证据。原始元数据、真实标识和解密缓存留在来宾私密目录。

入站 `source` 实际使用 Zstandard 压缩，现已增加 16 KiB 上限的解压与 XML 解析。真实 @ 样本的 `atuserlist` 包含已绑定账号 ID；自身消息的发送者 ID 与绑定账号一致。普通文本和手打假 @ 的来源 XML 均缺少 `atuserlist`，当前仍记为未知，未把字段缺失改判为明确的否定。因此真实 @ 与自身样本通过，完整 @ 对照准入尚未通过，发送和 dot 继续关闭。

新增的私密短时准入记录绑定来宾硬件标识、系统身份、Windows 用户、账号目录、客户端哈希以及进程创建时间。共享资源由本地操作者复核；每次读取命令重新核对环境。系统级 SMB 连接查询在普通权限下被拒绝，因此保留相同查询，由来宾管理员权限的限时只读进程每 5 秒更新受管理员写权限保护的结果。结果过期、出现连接、账号增加、进程变化或准入撤销均会停止读取。该记录是本地实验操作机制，不能作为对恶意管理员或所有网络通道的安全证明。

重新读取同一测试窗口并重开持久化记录后，记录保持四条，新增重复记录为零。这验证了本轮样本的读取与持久化去重，尚不等于微信断线恢复验证。测试结束后已撤销短时准入并停止管理员辅助检查。

本轮新增回归测试后，本地与实际来宾均通过 42 项离线测试，覆盖短时准入、环境变化、目录重定向、检查结果有效期和压缩元数据的大小限制。此前的 34 项验证是安装基线，具体结果如下。
